## RESSIKAN (2.44)

**RESSIKAN** (app 2.44, D51; Timothy's design over two mockups): station `ressikan` (REFLECT). All Web Audio, in one inner function `rs` (its own names; CSS all `rs-`): `rs.render/head/click/leave/card`. One room: bus → tape wow (modulated short delay) → lo-fi (staircase shaper, band-limit) → echo (dotted eighth of the tempo) and convolver reverb (generated impulse) → compressor → master, plus a MediaStreamDestination for RECORD (MediaRecorder; `audio/mp4` on Safari) and SAVE TO FILES (share sheet with a File, else a download). FIELD: theremin voices per pointer (sine + saw + detuned saw + sub → fold shaper → ring mod → low-pass with RESO → three formant band-passes for VOWEL → tremolo → pan), knobs applied live (`thApply`); ACROSS THE FIELD picks what x drives; HOLD keeps ≤ 4. Beat ring: 4 lanes of fixed steps (16/12/10/8), 16th-note scheduler with lookahead (1.5 s when the page is hidden), swing on odd steps, synthesized kick/snare/hat and FM electric-piano chords on a four-bar degree turn. DRIFT: generative pads only while its card is open; PLAY/DUET touches (bloom, swell, chimes; DUET answers with `dr.answer` odds); noise beds (wind/surf/rain). Engine life (2.44.1): `start()` builds a new AudioContext on every SOUND ON (closing the old; Safari's "interrupted" state never woke the reused one), SOUND OFF suspends it after the fade, and `onstatechange` away from running while on calls `lost()` (SOUND OFF, IPADOS PAUSED THE SOUND); e2e55 wraps `AudioContext` to check this. Settings in `tos.ressikan.v1` (BK_KEYS); `go()` calls `rs.leave()` so leaving is quiet. Tests: `app_e2e55`.
